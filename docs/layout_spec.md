# 简历排版规范（参考：基准版 PDF，2026-10 实测）

> 基准 = 基准单页简历 PDF（微软雅黑）。字体/字号/行距均为从 PDF 实测提取，不是估算。
> **数值真值在 `config/style.yaml`**；本文件记录依据与验收标准，改数值只改配置。
> 语言风格见 `src/resume_system/prompts/b_style.md` 和 `docs/style_rules.md`；本文件只管排版。

## 页面
- A4 单页（约 595 × 842 pt）
- 左右边距约 0.8 cm，上下边距约 0.8 cm

## 字体与颜色
- 正文/加粗：**微软雅黑（Microsoft YaHei）** 常规 + Bold。
- 顶头信息框（姓名/联系方式/到岗时间/求职意向）：**宋体（宋体-简 / STSongti-SC）**。
- 姓名 / 栏目标题：微软雅黑（姓名宋体）Bold + **强调色 accent**（默认随主题，见 `config/style.yaml`），标题下方细下划线同色。
- 其余正文：`colors.text`（默认近黑）。
- 注意：本机需装 `msyh.ttc`/`msyhbd.ttc`（微软雅黑）和 `Songti.ttc`（宋体）到 `data/assets/fonts/` 或系统字体目录，否则渲染会 fallback。

## 字号（固定，不缩放）
- 姓名：18pt 加粗
- 栏目标题：13.5pt 加粗，下方细下划线
- 正文：12pt（加粗片段同 12pt）
- 字号固定不缩放。内容超一页时，渲染器按相关度从低到高删字条，删到 1 页后再把删掉的按相关度从高到低**回填**（填满优先：放得下就留，放不下就跳过），直到既不超页也填得最满（不缩字）。

## 行距与段间距
- 正文行距：精确 12.7pt（≈ 单倍略紧）
- 同一经历内两条字条之间：+3.2pt（约 1/4 行）
- 项目行与第一条字条之间：+3.2pt（约 1/4 行）
- 同一板块内两段经历之间：+8pt（约 1/2 行）

## 顶部区
- 姓名（宋体 18pt 加粗）
- 联系方式（`电话 | 邮箱`，宋体，**不加粗**）
- 到岗时间（岗位专属；正文顶部写了就用正文的值，没写回退到 job task 的 availability，宋体；**只加粗第一个逗号前的值**，如「随时到岗」，其余如「每周到岗 5 天」保持常规）
- 求职意向（岗位专属；同上，回退到 job title，宋体；**不加粗**）
- 照片：右上角，高约 3.0cm（宽约 2.14cm），与姓名顶部对齐

## 栏目顺序（由 config/style.yaml 的 layout.order 控制）
默认顺序：
1. 教育背景（含：专业成绩、主修课程、荣誉奖项——荣誉作为「荣誉奖项：…」字段附在教育背景下）
2. 实习经历（internship）
3. 竞赛经历（competition）
4. 科研经历（research）
5. 校园经历（campus，含社区实践）
6. 技能（skills 标签，一行）
7. 个人能力（数据整理与分析 / AI 赋能 / 语言能力）

注：实习 / 竞赛 / 科研 / 校园四个经历板块**按 JD 相关度取舍**，无命中或不相关则省略，不硬凑空板块；教育背景与个人能力始终保留。

## 经历条目版式
每个项目一个块，结构：
1. **项目行**（单行三栏，用「｜」分隔：`时间｜项目名称｜角色`）——整行加粗；时间左对齐、项目名称居中（制表位 Cm(9.7)）、角色右对齐
2. **维度分点**（2–3 个，每行「**维度标签**：描述」，缩进两字符）

**教育背景行**（单行三栏，用「｜」分隔：`时间｜学校｜学院/专业（学历）`）——**不加粗**；时间左对齐、学校居中（Cm(9.7)）、学院/专业右对齐（Cm(19.4)）。

## 加粗规则
- 加粗：姓名、栏目标题、项目行（时间+名称+角色整行）、维度标签（bullet 开头的能力短语）、教育背景字段名（专业成绩 / 主修课程 / 荣誉奖项）、描述句内的数字/工具/成果词、个人能力标签
- **个人能力三条固定加粗"能力字段"**：数据处理 / 统计建模 / 分析结果解读 / 结果复盘 / 流程优化、信息处理 / 任务执行效率、英文专业资料阅读 / 英语母语者口语沟通；工具名与分数（Excel、SQL、Stata、CET-6 等）不加粗
- 不加粗：描述句其余文字、其他正文、教育背景行（时间/学校/专业）

## 段落与对齐
- 左对齐
- 正文/分点缩进两字符（约 15pt）
