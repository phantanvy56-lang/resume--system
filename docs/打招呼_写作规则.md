# 打招呼 · 写作规则（BOSS / 邮件 / 内推）

> 结构固定：能来 → 会干 → 下一步。
> 与简历字条的分工：字条是书面条目（能力短语：描述句），打招呼是对话体——只说你做过什么，不展开怎么做。
> 固定身份句（学校 / 届别 / 到岗 / 时长）来自本地 `data/greeting.md`，公开规则里不写死。

## 一、结构：固定三段

1. **能来**：身份 + 到岗 + 时长（一句，固定句式，不每岗重写）
2. **会干**：2–3 个能力词，贴 JD 原词，**不展开动作链**
3. **下一步**：发简历 / 约时间（一句）

固定句式（占位符，真实值由本地配置提供）：

> 您好，{学校}{专业}{届别}在读{去向}；{到岗时间}，每周可到岗 {天数} 天、可连续实习 {月数} 个月。

写死的部分不写死，每岗重新想了就是浪费。变的部分只有第 2 段的能力词。

## 二、能力词三条硬规则

1. **至少一个 JD 原词**，其余可用同期表述；**不造词**（“沟通能力强”“学习能力强”不是能力词）。
2. **只写有证据的职责**。没证据的用缺口话术收尾，不硬贴。
3. **2–3 个封顶**。写“岗位前三条”时，三条必须真的对应 JD 前三项，否则别用序数词。

参考词表（按岗位类型，用时替换）：

| 岗位类型 | 能力词 |
|---|---|
| 渠道 / 订单支持 | 订单处理与交付跟进 / 英文单据核对 / Excel 台账与报表 |
| GTM / 产品运营 | 竞品与市场分析 / 数据整理与报表 / 跨部门协同推进 |
| 跨境电商运营 | 运营数据整理 / 市场与竞品调研 / 内容与文案输出 |
| 官网 / 内容运营 | 内容维护与更新 / 素材与上线协调 / 运营数据复盘 |
| 职能支持（合同/资金） | 材料审核与合规 / 台账与信息留痕 / 多任务并行跟进 |
| 策略 / 数据分析 | 数据分析与建模 / 用户与客群分群 / 策略落地 |
| HR / 招聘 | 招聘执行与候选人沟通 / 简历与资格核验 / 数据与流程优化 |

## 三、禁写清单

- 自评：具备…能力 / 学习能力强 / 热爱 / 对…有浓厚兴趣
- 客套：非常感兴趣 / 恳请给个机会 / 期待您的回复
- 感叹号；一条消息里“贵司”出现两次以上
- 长篇动作链（“逐单跟踪订单从揽收到签收……”）——那是简历的活，打招呼里只给名词
- 解释自己为什么一般（“虽然我没有经验，但是…”）

## 四、渠道差异

| 渠道 | 名字 | 长度 | 备注 |
|---|---|---|---|
| BOSS 首条 | 不写（窗口顶部已有） | 80–150 字 | 3 行以内，对方三秒能读完 |
| 邮件 | 开头自报 + 落款 | 150–250 字 | 主题带岗位名 + 姓名 + 可实习时长；附件命名同 |
| 内推 / 转介 | 必须写 | 80–120 字 | 中间人转发时没有上下文，名字是唯一线索 |

## 五、自检五问（发之前逐条过）

1. 前 20 个字能不能看出“能来”？
2. 能力词里有几个是 JD 原词？少于 1 个就重写。
3. 有没有一句是自我评价？有就删。
4. 有没有主动说一句缺口？没有的话，遇到追问会慌。
5. 最后一句有没有给出下一步？（发简历、约时间、要邮箱）

## 六、模板

```
您好，{学校}{专业}{届别}在读{去向}；{到岗时间}，每周可到岗 {天数} 天、可连续实习 {月数} 个月。
岗位要的【能力词 A】、【能力词 B】、【能力词 C】，这三块我都实打实做过。
简历发您，方便的话看一眼，感谢！
```

**正例（虚构）**

> 您好，示例大学市场营销 2027 届在读，已保研；随时到岗，每周可到岗 5 天、可连续实习 6 个月。
> 岗位要的订单处理与交付跟进、英文单据核对、Excel 台账与报表，这三块我都实打实做过。
> 简历发您，方便的话看一眼，感谢！

**缺口话术（对方追问或岗位明显缺项时补一句）**

> 库存 PSI、SN 管理我没实操过，但核对的逻辑一致，给我两天熟悉表格结构就能上手。
