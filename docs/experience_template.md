# 经历信息采集固定模板

复盘每段经历时，A 按此模板追问并采集，确保不遗漏。模板从示范简历（示例简历）反推，保证后续 B 能产出同风格 bullet。

## 每段经历必须采集

### ① 基础信息
- 起止时间（精确到月）
- 组织 / 项目名
- 角色 / 职务

### ② 总体结果
- 这段经历的成果（获奖、排名、整体规模数字）

### ③ 工作块（拆 2–4 块，每块对应简历一条 bullet）
每块采集 5 要素：

1. **能力标签** —— 这块展示什么能力（名词短语，如「市场调研与数据分析」）
2. **动作** —— 具体做了什么（动词开头）
3. **方法 / 工具** —— 怎么做的（问卷、爬虫、Excel…）
4. **量化数字** —— 规模 + 结果
5. **个人贡献** —— 独立负责 vs 团队分工

## 一条 bullet 的拼法（供 B 参考，A 不产出成品句）

> **能力短语**：动词开头 + 具体动作 + 方法/工具 + 量化结果 + 价值

## 采集时注意

- 缺数字 → 追问；无量化结果时不编造，标 `open_question`
- 能力标签要反映真实行动，不拔高
- 无法确认的内容标 `pending` / `inferred`
